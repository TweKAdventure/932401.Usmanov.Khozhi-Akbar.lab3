Описание проекта:
  Персональное портфолио начинающего предпринимателя и стартапера Усманова Хожи-Акбара
  Сайт содержит информацию об авторе, его навыках, проектах, идеях стартапов и ключевых бизнес-метриках. Также предусмотрена контактная форма для обратной связи

Цель работы:
  Закрепить навыки создания веб-страниц с помощью HTML5 и CSS3, освоить технологии Flexbox и CSS Grid, а также научиться создавать адаптивные веб-интерфейсы

Содержание сайта:

1. Обо мне
Краткая информация об авторе и его интересах в предпринимательстве, маркетинге и технологиях

2. Навыки
Перечень основных навыков: маркетинг, управление командой, финансовая грамотность и презентация проектов

3. Мои проекты
Карточки проектов, посвящённых компьютерному зрению и финансовому образованию

4. Идеи стартапов
Четыре идеи стартапов с описанием проблемы и предлагаемого решения:
  VisionQC — автоматическое обнаружение дефектов с помощью компьютерного зрения
  FinStart — планирование бюджета и прогнозирование прибыли
  TeamFlow — управление задачами и сроками командной работы
  EcoTrack — анализ потребления ресурсов и экологичности процессов
Карточки организованы с помощью Flexbox

5. Ключевые метрики стартапа
Панель из трёх показателей:
  MAU — количество активных пользователей за месяц
  LTV — доход за всё время от одного клиента
  CAC — стоимость привлечения одного клиента
Показатели демонстрационные и используются для примера визуализации данных
Сетка метрик реализована с помощью CSS Grid

6. Контактная форма
Форма для ввода имени и сообщения

7. Боковая панель и подвал
Дополнительная информация о ценности проектов, целях автора и навигационная ссылка для возврата в начало страницы
